# Mega Lote 194 — Extrato Fiel + Central de Avisos V2

## Objetivo
Aplicar o layout de referência como padrão visual de extrato do crediário para prévia, PNG, PDF e compartilhamento, além de micro ajustar a Central de Avisos no mobile.

## Entregas
- Extrato do crediário com visual Jaque premium: logo grande, título forte, bordas, cabeçalho pink, tabelas, resumo e rodapé.
- PNG gerado com o mesmo padrão visual.
- PDF gerado a partir do PNG fiel para manter a mesma aparência.
- Compartilhar usa o arquivo gerado sem link solto.
- Central de avisos v2: modal mais polido, cards mais compactos, botões ajustados e painel PWA mais legível.
- Cache/PWA atualizado para v194.

## Observações
- Não houve alteração de banco, Supabase, RLS ou migrations.
- A geração de arquivos continua local no aparelho/navegador.
