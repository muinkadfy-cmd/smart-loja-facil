# Mega Lote 85 — Vendas/PDV premium web/mobile

## Foco
Refinar a aba Vendas/PDV com micro polimento, hierarquia visual, responsividade mobile-first, formulários mais legíveis, resumo mais forte e estados vazios comerciais.

## Melhorias
- camada CSS isolada v85 para Vendas/PDV;
- versão/cache/outbox atualizados para v85;
- helper do fluxo com linguagem mais simples;
- formulário de adicionar produto com respiro e campos maiores;
- tabela/carrinho com estado vazio mais profissional;
- painel Cliente mais legível;
- pagamentos com cards maiores e alinhados;
- resumo da venda destacado;
- botões com hierarquia mais clara;
- layout mobile em uma coluna quando necessário.

## Testes recomendados
1. Abrir Vendas/PDV no web desktop.
2. Testar usuário sem login / somente leitura.
3. Conferir adicionar produto, cliente e pagamento.
4. Conferir resumo e botões finalizadores.
5. Abrir no celular e verificar sem corte lateral.
