# Mega Lote 152 — Home mobile micro polimento

## Objetivo
Pequeno ajuste visual baseado nos prints reais do celular: deixar a home mais limpa, compacta e profissional no mobile, sem gerar imagem e sem mexer em dados reais.

## Alterações
- Header mobile mais compacto.
- Nome da loja continua protegido contra quebra, com melhor aproveitamento de espaço.
- Ícone da loja no header some em telas estreitas para liberar espaço ao nome.
- Card "Loja ativa" menor.
- Título da página e chip Online menores.
- Sub-abas contextuais aparecem só quando existe mais de uma opção útil.
- Dashboard com cards, ações rápidas e estado vazio um pouco menores e mais equilibrados.
- PWA/cache atualizado para v152.

## Segurança
Não altera venda, caixa, estoque, crediário, Supabase, backup, permissões ou login.

## Testes
Rodar: npm run type-check, build, lint, release:check, release:commercial:check, release:commercial:prepare e npm audit.
