# Mega Lote 102 — Login centralizado + contraste suave

## Objetivo
Aplicar correção visual sênior pedida pelo usuário:
- remover o bloco grande de letras no login;
- centralizar o cartão de login em web e mobile;
- reduzir poluição visual;
- deixar o fundo geral um pouco mais escuro para dar mais contraste;
- manter aparência comercial premium e mobile-first.

## Entregas
- `src/pages/Welcome.tsx`
- `src/components/WebAuthPanel.tsx`
- `src/styles/lote102-centered-login.css`
- `src/main.tsx`
- `src/lib/webApi.ts`
- `public/sw.js`
- `public/manifest.webmanifest`
- `scripts/release_check.js`
- `README.md`
- `package.json`

## Resultado esperado
- login limpo, centralizado e mais equilibrado;
- fundo geral menos branco estourado;
- sessão ativa com ações mais claras (`Abrir painel` e `Sair`);
- mesma base PWA web/mobile preservada;
- cache e versão atualizados para forçar atualização segura.
