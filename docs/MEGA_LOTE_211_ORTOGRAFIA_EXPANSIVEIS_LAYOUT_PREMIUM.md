# Mega Lote 211 — Ortografia, Expansíveis e Layout Premium

## Objetivo
Revisar textos visíveis, acentos, pontuação básica, abreviações e compactação de dados para usuário leigo.

## Ajustes aplicados
- Corrigido `CREDIARIO` para `CREDIÁRIO` nos títulos e extratos visíveis.
- Corrigido `crediario` para `crediário` nos textos principais dos comprovantes.
- Removida a palavra visual `Anotações` dos modelos HTML/A4, usando `Resumo`.
- Aba Comprovantes: clientes do crediário começam fechados por padrão para ocupar menos espaço.
- Produtos: card compacto por padrão; detalhes, custo, código, barras e ações aparecem ao tocar em `Detalhes`.
- Clientes: card compacto por padrão; endereço, limite, observações, WhatsApp e ações aparecem ao tocar em `Detalhes`.
- Crediário: `Próx. venc.` virou `Próximo vencimento`; plural robótico foi reduzido.
- Vendas: `item(ns)` virou `item/itens` conforme quantidade.
- Navegação: `Dashboard` virou `Painel`; `Comprov.` virou `Comprovantes`; `Diag. Web` virou `Diagnóstico`.
- Diagnóstico: textos de contagem técnica foram suavizados de `item(ns)` para `itens`.
