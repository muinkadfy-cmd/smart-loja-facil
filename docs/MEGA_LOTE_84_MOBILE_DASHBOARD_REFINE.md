# Mega Lote 84 — Dashboard mobile / quick access / hierarquia

## Foco
Refinar o dashboard no celular, corrigindo empilhamento do hero, textos verticais/quebrados em ações rápidas, grade de operação rápida e acabamento do topo mobile.

## Principais melhorias
- hero do dashboard empilhado corretamente no mobile;
- ações principais em grade 3x2 / 2xN sem texto vertical;
- status da loja com leitura em coluna;
- operação rápida em 2 colunas com botões maiores e textos legíveis;
- atalhos rápidos e mensagens do sistema com melhor respiro;
- quick access mobile com scroll horizontal confortável;
- dock inferior com toque mais estável;
- versão/cache/outbox atualizados para v84.
