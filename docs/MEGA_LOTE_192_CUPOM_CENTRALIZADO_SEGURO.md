# Mega Lote 192 — Cupom Centralizado Seguro

## Objetivo
Micro ajustar a aba Cupom após teste real no celular: centralizar melhor a arte e os textos dinâmicos, impedir que nome/código escapem das margens e melhorar o encaixe do desconto no espaço limpo.

## Entregas
- Desconto reposicionado e levemente reduzido para ficar mais centralizado.
- `%` e `OFF` alinhados com melhor equilíbrio visual.
- Nome do cliente reduzido, centralizado verticalmente e protegido por área de recorte.
- Código do cupom centralizado dentro do campo branco e protegido por recorte.
- Preview levemente menor no mobile para ganhar respiro dentro do card.
- Exportação PNG preservada em 1080×1350.
- Compartilhar PNG e baixar PNG preservados.
- Cache PWA atualizado para v192.

## Observação
Este lote não altera banco, Supabase, Storage ou permissões. O cupom continua sendo gerado localmente no aparelho.
