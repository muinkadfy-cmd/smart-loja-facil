# Mega Lote 209 — Crediário Fácil para Usuário Leigo

## Objetivo
Deixar a aba Crediário mais simples, segura e clara para operador leigo.

## Ajustes aplicados
- adicionado modo **Simples / Avançado** na aba Crediário;
- modo Simples mostra ações essenciais: Ver recibo, Receber e Corrigir;
- botão **Corrigir** abre assistente guiado com opções humanas;
- ações perigosas continuam disponíveis, mas guiadas;
- edição de valor/vencimento agora mostra prévia Antes/Depois;
- estorno e complemento agora mostram impacto no caixa e saldo antes de confirmar;
- adicionada confirmação obrigatória para salvar edição/correção;
- textos de sobra/falta foram reescritos para usuário leigo;
- mantida auditoria, motivo obrigatório, caixa e fluxo oficial;
- mantida compatibilidade com o lote 208.

## Fluxo para usuário leigo
1. Abrir a conta do cliente.
2. Tocar em **Receber** para pagamento normal.
3. Tocar em **Corrigir** quando digitou algo errado.
4. Escolher no assistente: mudar valor/vencimento, estornar, receber complemento ou ver recibo.
5. Conferir Antes/Depois e marcar confirmação antes de salvar.
